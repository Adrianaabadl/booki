# Booki Project

## Presentation of deliverables 
- You’ll present your work and explain your technical decisions. 
- Present an overview of the project background (what has been produced, why, and for whom).
- Present the visual appearance of the project, showing the mobile, tablet, and desktop versions.
- Present the project code in your development environment. Feel free to highlight the more complex aspects of what you had to produce.


## Review the project.


- The W3C validation of your code.
- The Semantic Web.
- Why it’s important to run your code through validators.
- How your development environment works.
- CSS specificity. 
- Mockup analysis and breakdown.
- Why it’s important to separate the HTML and the CSS code.

## Debrief 
At the end of the assessment session, the assessor will stop playing the role of Sarah so that you can debrief together.
